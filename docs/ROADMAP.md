# Roadmap

This roadmap is a compact index. The normative sequencing and gates are in `docs/implementation/IMPLEMENTATION_PLAN.md`.

The canonical architecture phases remain:
1. P1 Foundation and Judge v0.
2. P2 Code-first and mutation sources.
3. P3 Spec Forge.
4. P4 Verification Forge.
5. P5 Solver, Exporter and the deciding transfer experiment.
6. P6 RL environment and flywheel.

Before P1, complete Bootstrap Gate B0 for governance, tasking, handoffs and CI. B0 is not a seventh architecture phase.

Agents are never assigned a whole phase. Work is opened only as bounded TASK-IDs under dependency-ready subphases.
