# Data/Exporter-specific rules
- Preserve family/lineage/task/variant identity through every derivative.
- Never move descendants across train/dev/final lineage boundaries.
- Customer/private/final-eval data cannot enter shared training unless explicit rights/policy allow it.
- Infrastructure failures and inconclusive proofs are not negative RTL labels.
- Every exported record includes provenance, evaluator version/evidence level, producer model/license tag, and assistance level.
- If an evaluator defect invalidates labels, affected exports must be traceable for regeneration/withdrawal.
